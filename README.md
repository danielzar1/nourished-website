# Nourished WordPress Theme

Modern e-commerce theme for Nourished Natural Sweets.

## Installation

1. Download or upload this theme to `/wp-content/themes/nourished/`
2. Activate the theme in WordPress admin
3. Copy the `assets/vendor`, `assets/js`, and other asset folders from the original static site

## Assets Required

This theme requires the following folders from the original static site:

- `assets/vendor/` (GSAP, ScrollTrigger, confetti libraries)
- `assets/js/` (products.js, components.js, cart.js, fx.js, shop.js)
- `assets/products/` (product images)

## Configuration

Edit `assets/js/products.js` to configure:
- Store currency and shipping rates
- Product catalog
- Brand messaging

## Features

- Responsive design
- Shopping cart with localStorage
- Product catalog with filters
- Animation effects (GSAP, confetti)
- Accessibility-ready
- Mobile navigation
